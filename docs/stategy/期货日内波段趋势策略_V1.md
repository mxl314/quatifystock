# 期货日内波段趋势策略 V1

## 1. 策略目标

以日线结构确定大方向，以当前交易时段开盘价过滤日内方向，以 3 分钟 K 线识别回撤结构，并使用 Tick 实时触发入场。策略仅做日内交易，支持期货多空双向开仓。

## 2. 数据分工

- 日线：判断中期趋势，不与日内 K 线混用。
- 3 分钟 K 线：确认日内高低点和回撤结构。
- Tick：实时判断价格过滤条件、入场阈值、止损及成交。
- 合约信息：合约乘数、最小变动价位、保证金率、手续费和平今规则全部参数化，禁止写死。

## 3. 交易时段与开盘价

- 不设置“开盘后 15 分钟不交易”的观察期。
- 策略在交易时段产生首个有效 Tick 后即可开始判断。
- 开盘价使用交易所行情给出的当前 session 开盘价，不使用“程序启动后若干分钟”的价格代替。
- 日盘和夜盘分别维护 session；跨休市时段不得沿用上一个 session 的开盘价。
- 同时记录交易日开盘价和 session 开盘价，V1 实盘判断默认使用 session 开盘价，后续用回测比较两种口径。
- 3 分钟 K 线只用于构造拐点，不用于定义开盘价。

## 4. 日线趋势

使用 ATR(14) 与已确认的日线 Swing 高低点：

- `L2 > L1 && H2 > H1`：多头趋势。
- `H2 < H1 && L2 < L1`：空头趋势。
- 其他结构：震荡，不开新仓。

Swing 的确认规则必须避免使用未来数据；回测和实盘使用同一确认逻辑。

## 5. 方向过滤

| 日线趋势 | 当前价格与 session 开盘价 | 状态 |
| --- | --- | --- |
| 多头 | 当前价 > 开盘价 | `LONG_ONLY` |
| 空头 | 当前价 < 开盘价 | `SHORT_ONLY` |
| 其他 | 任意 | `WAIT` |

价格恰好等于开盘价时保持 `WAIT`。方向状态可以随 Tick 更新，但已有持仓不因过滤状态改变而立即反手。

## 6. 入场结构

### 做多

1. 当前状态为 `LONG_ONLY`。
2. 3 分钟 K 线依次形成 `L1 -> H1 -> L2`。
3. `L2 > L1`，表明回撤没有破坏抬高的低点结构。
4. L2 被确认后，价格自 L2 向上反弹达到入场阈值时，由 Tick 触发做多。

### 做空

1. 当前状态为 `SHORT_ONLY`。
2. 3 分钟 K 线依次形成 `H1 -> L1 -> H2`。
3. `H2 < H1`，表明反弹没有破坏降低的高点结构。
4. H2 被确认后，价格自 H2 向下回落达到入场阈值时，由 Tick 触发做空。

默认入场阈值为 `0.2 * ATR`。ATR 使用哪个周期、是否限制最小 Tick 数，需通过回测最终确定；计算结果必须按合约最小变动价位取整。

## 7. 止损与冷却

- 多单的结构止损位放在 L2 下方，空单放在 H2 上方。
- 默认缓冲为 `0.15 * ATR`，并按最小变动价位取整。
- 单次止损后禁止立即在同一结构重复入场。
- 冷却时间候选值为 5、10、15、20 分钟，最终值由回测选择。
- 交易时段结束前必须按配置处理平仓；不允许无意中把日内仓位带入下一 session。

## 8. 期货专属约束

- 明确区分开多、开空、平多、平空以及平今指令。
- 仓位大小按账户风险、止损距离、合约乘数和保证金约束共同计算。
- 手续费模型应支持按手、按成交额、平今差异三种情况。
- 主力合约切换、涨跌停、集合竞价、无有效报价、断线重连时禁止盲目触发信号。
- 夜盘归属交易日必须由交易日历或柜台字段确定，不能用自然日简单推算。
- 每个合约和 session 独立维护状态，严禁跨合约复用拐点或开盘价。

## 9. 状态机建议

```text
WAIT_DIRECTION
  -> SEEK_L1_H1_L2 / SEEK_H1_L1_H2
  -> WAIT_REBOUND_TRIGGER
  -> POSITION_OPEN
  -> EXITED
  -> COOLDOWN
  -> WAIT_DIRECTION
```

出现 session 切换、数据缺口、合约切换或结构失效时，清空未完成结构并回到 `WAIT_DIRECTION`。

## 10. 待回测参数

| 参数 | 初始值/候选值 |
| --- | --- |
| 日线 ATR 周期 | 14 |
| 入场反弹幅度 | 0.2 ATR |
| 止损缓冲 | 0.15 ATR |
| 止损后冷却 | 5 / 10 / 15 / 20 分钟 |
| 开盘价口径 | session / 交易日 |
| 日内 K 线周期 | 3 分钟 |

## 11. 实现边界

V1 先完成信号、风控和回放一致性，不在没有回测证据的情况下加入止盈、加仓、反手或多品种组合逻辑。建议按 `DailyTrend`、`DirectionFilter`、`IntradayPivot`、`EntrySignal`、`PositionSizer`、`StopLoss` 和 `SessionManager` 拆分模块。

## 12. 日线数据不足时的降级规则

- 日线完成 K 线不足 30 根时，使用 60 分钟已确认 Swing 高低点判断趋势。
- 60 分钟周期必须至少形成两组已确认高点和低点，否则保持 `WAIT`。
- 日线达到 30 根后自动切回日线；日线结构尚未确认时保持 `WAIT`，不再回退到 60 分钟。
- 实现类为 `quant_framework.strategy.AdaptiveTrendFilter`。
- 运行时需要在 `bar_intervals` 中包含 `3600`。日线应从可信历史源载入，或使用交易所交易日历聚合；不得直接按自然日切分夜盘 Tick。
